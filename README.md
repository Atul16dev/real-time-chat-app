# 💬 Real-Time Chat Application (MERN Stack)

A **Real-Time Chat Application** built as a **college mini project** using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** with **Socket.io** for real-time communication and **Cloudinary** for storing media files.

This application enables users to send and receive messages instantly without refreshing the page. It supports **text messaging, media sharing, notifications, and a modern responsive user interface**.

---

## 🚀 Features

- User Authentication (Login / Signup)
- Real-time messaging using **Socket.io**
- Send and receive text messages instantly
- Upload and share media files (images)
- Media storage using **Cloudinary**
- Message notifications
- Online / Offline user status
- Modern and responsive UI
- Chat history stored in **MongoDB**
- User search functionality

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- Socket.io Client

### Backend
- Node.js
- Express.js
- Socket.io

### Database
- MongoDB

### Media Storage
- Cloudinary

### Authentication
- JSON Web Token (JWT)
- bcryptjs

---

## 🏗 System Architecture

Client (React)  
↓  
Socket.io Client  
↓  
Node.js + Express Server  
↓  
MongoDB Database  
↓  
Cloudinary (Media Storage)

Socket.io enables **real-time bidirectional communication** between users.
